# 吞噬史莱姆：无尽成长

第三版美术方向的可玩 3D 网页游戏：研究基地、糖果街区、熔岩神殿。打开立即进入第一关，无启动页。移动端竖屏触控，电脑支持鼠标拖动、WASD 与方向键。

## 游玩

- 在线：https://2324621372.github.io/slime-devour/
- 离线：下载 `public/index.html`，用支持 WebGL 2 的现代浏览器打开。全部 JavaScript、Three.js、场景模型、样式与关卡数据均已内联，不需要 CDN、图片、字体或音频网络请求。
- 手机：在游戏空白处拖动控制方向，松手停止。横屏自动暂停并提示旋转。
- 右上角切换关卡 / 无尽；点关卡名称选择已解锁的关卡。暂停、重开、声音与画质均在局内调整。
- 只能吞比自己小的果冻；红色刺球、蜜蜂、激光等会造成伤害。连续吞噬维持 1.2 秒连击窗口，最高 5 倍得分。
- Boss 蓄力时躲开冲刺，进入虚弱窗口后靠近反击。熔岩 Boss 有三次反击阶段、震波和分裂怪。
- 星级、解锁进度、最高分与设置保存在当前浏览器的 `localStorage`，不跨设备同步。

## 内容与数值

包含 12 关、无尽模式、吞噬体积增长、Perfect 加分、无伤奖励、三星评价、音效与自动画质。场景沿用第三版温室、研究所、水庭、管线、糖果店、生产设施、门廊、祭坛、晶簇与火盆模型，静态零件按材质合并。

`src/levels.json` 从用户提供的 CSV 主表导入，原表保留在 `docs/level-design.csv`。场景由三套主题环境复用；各关使用不同目标和机制（漂流、蜜蜂、滚动威胁、激光、连击、冰面惯性、低重力、Boss、终局收缩）。没有为每一关另建一套独立地图。

可玩性调整：初始猎物使用 CSV 半径范围；后续猎物按当前体型的 43%–92% 生成，吞噬后在附近补充，避免固定小猎物导致成长目标无法达到。分数保留体积、连击、危险加成、Perfect、阶段和无伤公式，并加入实体基础分，匹配 CSV 的得分阈值。无尽成长在同一主题竞技场内持续推进六阶段，使用显示半径归一化与镜头变化；尚未制作真实城市尺度的独立街区、家具和建筑可吞物模型。

## 开发

Node.js 22 或更新版本：

```sh
npm ci
npm test
npm run build
```

产物为 `public/index.html`，约 0.6 MiB。打开源码入口需要支持 npm 模块的开发服务器；直接游玩请使用构建产物。

浏览器集成验证：

```sh
npm run build
npm run test:browser
```

默认使用 Windows 安装的 Edge；其他环境设置 `BROWSER_PATH` 为 Chromium 浏览器可执行文件路径。测试阻止所有 HTTP/HTTPS 请求，检查单 HTML 离线启动、真实触摸移动、吞噬成长得分、暂停、重开、无尽切换、设置存档、后期关卡与横竖屏。

## 发布

推送 `main` 后，GitHub Actions 运行规则测试、构建单文件并部署到 GitHub Pages。仓库 Pages 的构建来源为 GitHub Actions。

## 性能与限制

自动画质在触摸设备优先使用流畅模式，限制像素比并关闭实时阴影，桌面可选择精美模式。已经通过桌面 Chromium 的移动端模拟检查；没有在真实 iOS / Android 硬件上测量帧率，因此不承诺所有手机均为 30–60 fps。需要 WebGL 2。移动系统的文件预览器可能不执行 HTML，离线文件须交由实际浏览器打开。
